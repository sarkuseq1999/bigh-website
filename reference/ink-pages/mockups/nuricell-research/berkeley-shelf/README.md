# Berkeley bookshelf

November 20, 2026. A proposed watercolor for NuriCell’s ingredient research. Seven clothbound journals on a redwood sill look out over a live oak and the East Bay hills. Mo chose plain spines. Publication years appear in the study list. The two 2003 books share the comparison between the two reviews.

Mo approved this design for the NuriCell page on November 20, 2026. The browser overlay uses the existing product page’s buttons, answers and links. On phones, the heading and the tap instruction come before the books.

The original and its prompt are named `research-berkeley-shelf-v1` under `reference/ink-pages/nuricell/`. The painting uses the built-in image generator.

From this directory, run `python -X utf8 review.py <production-build-base-url>` to photograph both sizes, exercise every book and regenerate the standalone interactive review in `preview/`. Run `python serve.py <local-network-address> 3149` to view it from the same Wi-Fi. The server reads the site’s locally installed Switzer font.

## Mo's rules for this site (collected)

- **Timeline is her number one design reference**: calm, one idea per screen, generous space,
  centered statements. Borrow the vibe, keep BiGH's palette and fonts. Design vault first.
- **Never paste flat vector shapes on a photoreal render.** She called it "very fake". Effects must
  be a second render in the same style or changes to the render's own pixels (shader).
- **No red-dot or pathogen visuals.** Warm gold light and lime only.
- **No rats visible in the research section.** Say "animal study"; the word may appear only in the
  linked paper.
- **Large labels and navigation** for older readers.
- **Honesty lines stay**: "Illustration, not a measurement" on the aging visual; sample testimonials
  labeled fictional in five languages; "ingredient research does not establish the effects of a
  finished BiGH product" under the research list.
- **Copy voice**: understated, concrete, no hype; workshop and lock words before design.
- **Ask before every push.** The repo is public.
- **Plans in chat, ELI5, labeled choices** (1 · 2 · 3 · something else).

## How to run, check, ship

- Dev server: the app's preview "bigh-website" (`.claude/launch.json`), or
  `npm run dev -- --port 3007`.
- Static checks: `npm run type-check`, `npx eslint src`, `npm run format:check` (three old files,
  `docs/brand-assets.md`, `docs/cellular-health-comparison.md`,
  `public/experiments/product-comparison.json`, fail only because of CRLF in this checkout; leave them).
- Browser checks (Playwright for Python, already installed): `python -X utf8 scripts/qa/qa_glass.py
http://localhost:3007 ",kr"`; also `qa_research.py`, `qa_closing.py`, `qa_stories.py`. Pictures
  land in `scripts/qa/out/` (ignored by git). Full-page screenshots break the svh layouts; the
  scripts stitch viewport shots instead.
- Deploy: `vercel deploy --yes --scope sarkuseq1999s-projects`, then
  `vercel alias set <deployment host> bigh-website-demo.vercel.app --scope sarkuseq1999s-projects`,
  then run the QA scripts against `https://bigh-website-demo.vercel.app`. Notes in
  `docs/public-demo.md`.
- Design references: `/design-vault` works here through a junction into bigh-skills
  (`.claude/skills/design-vault`); it reads that repo's `.env`.
- Images: the Higgsfield plan (CLI, `higgsfield` typed in full, 19 credits) until September 27; after
  that Gemini for stills unless Mo picks GPT Image 2.5 through the API. Prompts and originals for every
  render live in `reference/*/originals/` next to a `.json` sidecar.
- Line endings: files are LF, the checkout has `core.autocrlf=true`; never `git stash`; Python writes
  need `newline="\n"`.
